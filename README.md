# Engine Testers

A small browser prototype for Second Shift, a desert backroad gas station and repair shop.

## Run

```sh
npm install
npm run dev
```

Use WASD or the touch controls to move. Click the scene and move the mouse to look around; press Esc to release the mouse. Press E by the garage to clock in, and use Open Garage to raise the doors. On mobile, drag the scene to look around.
