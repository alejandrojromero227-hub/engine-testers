# Engine Testers

A small browser prototype for Second Shift, a desert backroad gas station and repair shop.

## Run

```sh
npm install
npm run dev
```

Use WASD or the touch controls to move. Click the scene and move the mouse to look around; press Esc to release the mouse. Press E by the garage to clock in, then use E at the wall switch to open the bay doors. Pick up tools from the workbench, select them with 1–3, and press E near the Bay 01 car to repair it. Mobile players can drag to look, use the touch controls to move, and tap Use to interact.
